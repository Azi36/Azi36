在 GitHub 上免费部署静态网站

2024-06-18 14:33 · 预计阅读 5 分钟 · 作者：Azi36

不用买服务器、不用花一分钱，就能把一个网站放到公网上—— 这就是 GitHub Pages。本站（azi36.com）就是这么部署的， 整个流程走下来大概十分钟，这篇把每一步都写清楚。

第一步：新建项目并上传网站文件

登录 GitHub 新建一个仓库（设为 Public）， 把网站文件传上去。最少只需要一个 index.html 作为入口， 用 git 推送或者在网页上 Add file → Upload files 拖进去都行： 

git init
git add .
git commit -m "我的第一个网站"
git branch -M main
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main

第二步：开启 Pages，分支选 main

进入项目管理面板的 Settings → Pages， 把部署分支修改为 main：

保存后等一两分钟，页面上方会出现网址。 如果不配置自己的域名，默认地址就是 你的用户名.github.io/项目名，到这里网站已经上线了。

第三步：设置 Custom domain（自定义域名）

有自己的域名的话，在同一个页面的 Custom domain 填入域名并保存，GitHub 会自动在仓库根目录生成一个 CNAME 文件，内容就是你的域名：

第四步：域名 DNS 配置

到你的域名注册商的 DNS 设置里， 先添加 4 条 A 记录（这些 IP 是 GitHub Pages 的固定地址）：

类型名称值
A@185.199.108.153
A@185.199.109.153
A@185.199.110.153
A@185.199.111.153

再添加一条 CNAME 记录，把 yourusername 换成你的 GitHub 用户名：

类型名称值
CNAMEwwwyourusername.github.io

第五步：对域名做 DNS 归属验证

为了防止别人抢绑你的域名，建议再做一次验证： 打开 GitHub 个人设置（不是仓库设置）里的 Settings → Pages，点 Add a domain， GitHub 会给你一串验证内容，回到 DNS 设置里加一条 TXT 记录：

类型名称值
TXT_github-pages-challenge-你的用户名GitHub 给出的验证内容

解析生效后回到 GitHub 点 Verify，看到绿色对勾就完成了。

关于 SSL 证书（可忽略）

GitHub Pages 勾选 Enforce HTTPS 后会自动签发证书， 不需要自己申请。如果以后要给其他服务配 HTTPS， 可以在 腾讯云 等平台申请免费证书。

几个小贴士

  • 在根目录放一个空的 .nojekyll 文件， 告诉 GitHub 跳过 Jekyll 处理，纯 HTML 站部署更快更省心
  • 放一个 404.html，访客走错路时能看到你的自定义页面
  • 之后改完代码只管 push，大约一分钟内自动生效
你现在看到的这个网站，从第一行代码到上线，用的就是上面这套流程。
