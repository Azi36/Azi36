Az-term 终端工具

桌面版 Windows / macOS · 免费 · 开源 MIT · 网址：term.azi36.com

连服务器的软件，市面上不缺。缺的是不问你要账号、不掐试用期、 不把 SFTP 和常用指令这种基本功能锁进订阅里的那种。 Az-term 就是照这个标准做的：装完打开就能连，一分钱不花，一封邮件不填。

一台服务器，一个标签

左边侧栏是服务器列表，单击看配置，双击直接连。 每台服务器占一个标签，标签里面分四页：终端 · 文件 · 隧道 · 配置。 不用为了看一眼配置就跳出去开新窗口，也不用为了传个文件另开一个软件。 切走的终端还活着 —— 回来接着敲，正在跑的东西不会断。 Ctrl+Tab 换标签，Ctrl+1..9 直接跳第几个。

逐个说

① SSH 终端

Rust 侧用 russh 自己实现的引擎，前端 xterm.js 画布，真 PTY、真颜色、真 resize。 回滚 5000 行，Ctrl+F 在里面搜；Ctrl+Shift+C / V 复制粘贴 （Ctrl+C 留给中断，规矩不能乱）。配色六套（每套深浅两版）、字号四档， 改完所有开着的终端立刻跟着变，不用重连。 30 秒一次保活包，挂着不动也不会被中间的网关悄悄掐掉。

  • 三种认证：密码、公钥，以及 keyboard-interactive —— 所以开了 2FA / OTP 的机器也能连，验证码在弹窗里填
  • 编码热切换：UTF-8、GBK、GB18030、Big5、Shift_JIS、EUC-KR、Latin-1 七种， 连着不断线直接换。老国产机器打出一屏乱码，不用重连也能救回来
  • 掉线自己接：断了按 3 → 6 → 12 秒退避重连，但只在手上有凭据时才接； 也能设闲置多少分钟自动断
  • 会话日志：把这次会话的输出抄进文件，出了事有据可查

② SFTP 文件管理

左本地右远程双栏对照，跟老牌 FTP 工具一个手感，但该有的现代功能都有：

  • 多选：Ctrl 加减、Shift 选一段，批量传批量删
  • 整个目录传：目录递归展开成任务丢进队列，不是"只能传文件"
  • 断点续传：传到一半断了，下次从已传的位置接着走，不用从头再来。 取消时半截文件会删掉，续传的那种保留
  • 传输队列：默认三条车道并发跑，进度实时更新，可取消、失败可重试
  • 撞名先问你：同名文件先比大小和时间，让你选覆盖 / 跳过 / 续传，不闷头盖掉
  • 目录同步：只推"对面没有的"和"对面旧了的"。 不做同步删除 —— 单向少传总比多删安全
  • 拖拽上传：从资源管理器把文件或文件夹拖进右栏，松手就传
  • 收藏目录：常去的目录加星，本地一套、每台服务器各一套，一键跳
  • 其它：排序、按名过滤、隐藏文件开关、chmod 改权限、栏内复制移动、新建文件建完直接打开

SFTP 走的是终端那条连接的子通道 —— 不重新认证，不用二次输密码。

③ 远程文件直接编辑

改服务器配置的老流程是：下载 → 本地编辑器打开 → 改 → 记得上传 → 忘了上传 → 改了半天没生效。 Az-term 里点一下 ✎，文件在自己的标签页里打开，改完 Ctrl+S 直接写回原路径。 不落临时文件、不叫外部编辑器、不用手动上传。带行号、查找替换、跳行；标签上有小蓝点提醒你还没存。

为了不让你把二进制文件改坏：超过 2MB 不开，不是 UTF-8 文本也不开。

④ 指令库

常敲的那几十条命令存一次，以后点一下就填进终端，或者按 ▶ 直接执行。 内置 45 条预设（系统、磁盘、进程、网络、服务、日志、Docker、Nginx、Git、文件）， 按组勾选导入，不用从零敲。再也不用狂按 ↑ 翻历史。

⑤ 端口转发与跳板机

标签里的隧道页，三种转发都在，复用的还是终端那条已经认证过的连接 —— 不用另开一个 ssh 命令窗口挂着：

  • 本地转发（-L）：把远端的 3306 映到本机，用桌面上的客户端连"本地"数据库
  • SOCKS5 动态代理（-D）：握手是自己实现的，浏览器挂上就走服务器出网
  • 远程转发（-R）：把本机的服务反向暴露到服务器那一侧

跳板机（ProxyJump）：先连堡垒机，再从它连目标机， 跳板自己也支持密码或密钥。生产环境不给直连的那种网，这条路是必需品。

⑥ 备忘录

端口开了哪些、这台机器是谁的、上次那个坑怎么绕的 —— 随手记在软件里， 跟服务器标签平级，随时切。停手就自动存，纯本地，不同步不上传。

凭据这块，说清楚

密码和私钥密码短语交给操作系统的钥匙串（Windows 凭据管理器 / macOS Keychain）， 我们自己的配置文件里一个字节明文都没有，前端代码也拿不到 —— 它只能问"这条记过没有"， 真正取用在 Rust 侧连接时完成。私钥本身只存路径，内容连接时才读，不落盘不进日志。

主机指纹用标准的 ~/.ssh/known_hosts，跟系统 ssh 命令共用一份： 你在别处 ssh 过的机器这里直接认。默认策略是头一回连自动记下来不打扰你， 指纹变了才拦住报警 —— 那才是该停下来看一眼的时候。想更严格，设置里能改成每次都问。

换台电脑，不用从头填

服务器列表、指令库、备忘、设置都能导出成一个 JSON，换机器导回去就行。 导出的文件里不含任何密码 —— 明文导出会把"不落明文"这件事整个作废， 所以到了新机器上密码得重填一次，这是故意的。

本来就用命令行的话更省事：直接从 ~/.ssh/config 把主机列表扫出来，勾选成组导入。

为什么是自己写的

底座是 Tauri v2： Rust 内核 + 系统 webview，安装包十几兆，不是那种一装几百兆的 Electron。 SSH / SFTP 引擎用 russh 从零接，没有 fork 现成的终端软件 —— 这样以后要往里塞数据库管理、Redis、API 调试，都是同一个内核往外长。

还差什么

老实交代：分屏与输入广播还没做，FTP 也还没接 （协议选项在界面上灰着，标着"稍后"）；数据库和 Redis 面板在侧栏排着队，还没轮到。 云同步不在计划里 —— 真要做也只会走你自己的 WebDAV，不做"我这边的云"。 日常那部分已经齐了：连上去敲命令、传文件、改配置、开隧道、过跳板机。 而这些一样不锁付费墙。

常见问题

为什么免费？以后会收费吗？
所有连接都是你的电脑直连你的服务器，我这边不经手任何流量，也没有账号系统要养。 没有服务器成本，收费没道理。不收。

安装时提示"未知发布者"？
没做代码签名（个人证书一年好几百，暂时省了）。Windows 点"仍要运行"， macOS 去「系统设置 → 隐私与安全性」点"仍要打开"。介意的话可以自己从源码构建。

支持 Linux 吗？
Tauri 本身支持，源码自己构建能跑，只是 CI 里目前只出 Windows 和 macOS 包。

配置能同步到别的电脑吗？
还不能。将来做也只会走你自己的 WebDAV 或服务器，不做"我这边的云"。

不注册、不过期、不锁功能 —— 工具本来就该长这样。
