Az-im 图像工具

2026-08-17 上线 · 免费 · 开源 MIT · 网址：im.azi36.com

处理图片这件事，网上的工具要么要注册，要么要会员， 要么把你的图传到它们的服务器上转一圈。 Az-im 一样都不沾：打开就用，用完就走，图片从头到尾待在你的浏览器里。

四件套，逐个说

① 图片压缩

主力工具，日常用得最多的就是它。支持 JPEG / PNG / WebP / GIF / SVG / AVIF 六种格式，还能吞 iPhone 拍的 HEIC / HEIF。 文件、文件夹、拖拽、Ctrl+V 粘贴，怎么进来都行，几百张一起处理也不打怵。

  • 压缩：每种格式用各自最合适的引擎（JPEG 用 MozJPEG、PNG 用 OxiPNG……）， 质量、颜色数、抖色系数都能调，还有一个"极限模式"给抠体积的人
  • 转换：JPG、PNG、WebP、AVIF 互转，透明背景转不透明格式时可以自选填充色
  • 缩放裁剪：八种模式 —— 按宽、高、长短边、百分比缩放；按比例、固定尺寸、 打印纸型（A3/A4/A5/Letter/Legal/B4/B5）裁剪； 公众号封面、小红书 3:4、B 站封面这类常用尺寸一键填入
  • 存成预设：调好的一整套参数存下来，下次一键套用。 内置平衡 / 公众号配图 / 网页配图 / 保清晰 / 极致压缩五个，自己还能再存十二个
  • 单张开小灶：整批用一套参数，某一张不满意就单独给它改，只重压它自己，不动其他
  • 多核一起上：压缩跑在 worker 池里并行，几百张的时候真吃得到多核； 中途能停，某个 worker 崩了会换新的顶上
  • 挑得出问题图：列表能筛"失败 / 已停止 / 反而变大了"， 也能按体积或压缩效果最差排序
  • 交付：处理前后拖分割线对比画质，逐张下载或整批打包 ZIP（打包有进度）

压缩率看图片内容，通常五到九成。一张 32KB 的测试图能压到 4.8KB，肉眼看不出差别。

② 背景移除

丢一张图进去，主体留下，背景变透明，出 PNG。模型有两档，按需选：

档位模型体积适合
快速U2-Netp4.4MB秒出结果，日常够用
高质量Silueta42MB边缘细节更完整，处理慢一点

切换模型时如果已经有图，会自动用新模型重跑一遍，不用重新选图。 结果底色能在格纹 / 白 / 黑之间切，方便看边缘干不干净； 出图可以直接下载，也能一键复制进剪贴板，粘到别处就用。

③ 图片放大

AI 超分辨率（Real-ESRGAN），把小图放大 2 倍或 4 倍——细节是神经网络重建出来的， 不是硬拉的马赛克。大图会切块推理，进度条一块块走，页面不卡。 目前限制长边 2000px 以内（更大的先去压缩页缩一下）。

④ 去水印

把水印、logo、路人甲涂红，点「移除」，周围的像素会智能补上。 画笔 8–80px 可调，修完不满意接着涂接着修，逐步清干净。 涂错了能逐笔撤销，修坏了能撤销上一次修复或直接还原原图， 往回退十步都有。 用的是经典修复算法（OpenCV），对小面积水印、文字、杂物效果最好； 大面积的复杂遮挡，等后续上大模型。

快，是因为根本没上传

一般的在线工具：你的图 → 它们的服务器 → 处理 → 传回来，来回两趟运费。
Az-im：你的图 → 你的浏览器 → 完事。 压缩靠 WebAssembly，AI 靠本地跑的模型，显卡够新还会自动用 WebGPU 加速。 没有上传队列，没有服务器留底，关掉页面什么都不剩。

AI 在浏览器里跑？

对。神经网络模型会在第一次使用时下载到浏览器缓存，之后再用就不重新下了。 推理优先走 WebGPU（用显卡，快），浏览器不支持或者显卡不给力就自动退回 CPU， 你不用管，页面右上角的小徽章会告诉你当前在用哪个。 全程不需要 API、不需要 key、没有服务器账单——所以它才能一直免费、不限量。

三步上手

  1. 丢图进来——点选、拖拽、粘贴，随意
  2. 调一下——压缩挑参数，抠图挑模型，放大挑倍数，去水印动笔涂
  3. 带走——单张下载或打包 ZIP，完事关页面，什么都不留

常见问题

真的不上传吗？
真的。不信按 F12 打开网络面板自己盯着：处理图片时没有任何上传请求。 代码也开源，欢迎审计。

第一次用为什么要等一会儿？
在下模型。下完存进浏览器缓存，第二次起秒开。

手机能用吗？
能，页面是响应式的。AI 功能在低配设备上会慢一些，压缩不受影响。

放大提示图片太大？
长边超过 2000px 了。先去压缩页把尺寸缩到范围内，再来放大。

为什么免费？以后会收费吗？
成本上它没有服务器开销（静态托管 + 你的设备出算力），收费没有道理。 不收，也不打算收。
